## 年级选择后空白修复（2026-10-26）

用户真机反馈选完年级后内容空白、底部导航无法操作。根因是 Capacitor 6 默认将无扩展名文档返回根 index.html，而 Next 静态导出为每个页面生成独立 index.html。首页根据已选年级再次跳转同一路径，形成循环刷新。此前普通静态浏览器验收没有覆盖容器的这项回退行为。

家庭原生 WebViewClient 现将同源主文档 GET 请求映射到对应目录的 index.html，再交给 Capacitor 原有处理逻辑，保留桥接注入与导航生命周期。脚本、JSON、RSC、API、子资源、跨源和非 GET 请求继续走原流程。

新增纯 Java 回归覆盖 4,189 个导出页面，并检查外部来源、端口、路径穿越及子资源不被改写；已纳入家庭构建。发布编译/Lint 与 13 项连接测试通过。最终 APK 已确认包含原生适配类，签名证书指纹与上一版一致；包内 12,567 文件隐私检查通过。

本地对照服务的旧回退规则复现选年级后的循环刷新；按导出目录提供文档后，年级课程页和“我的”导航可正常加载。纯 Java 和浏览器对照不能替代真机 WebView；新版需由用户覆盖安装复测，没有声称已在用户手机上验收通过。

## 家庭界面与教材入口简化（2026-10-26）

按用户最终要求：移除“我的”页打赏支持入口；家庭 AI 卡片移到家长时间设置之后、存档备份之前；教材中心提供国家中小学智慧教育平台的查找/登录/下载指引，GitHub ChinaTextbook仅作备用入口。不再显示或同步全量 GitHub 目录，不新增下载系统、PDF 阅读器或国家平台登录采集。

最终 2606 发布编译、类型/Lint、4189 文档路由回归和签名检查通过。APK 内 12,568 文件秘密比对与私钥/本机路径检查通过。检查最终 profile HTML 确认没有打赏入口，AI 位于家长设置之后；教材 HTML 包含两个固定 HTTPS 入口及官方登录提示，无目录加载依赖。浏览器已确认最终教材页面显示正常。官方平台账号、下载能力和真机外部浏览器跳转未在本轮代用户操作或验收。

## 教材分类与跳转确认（2608）

中小学走国家平台，大学单独直达GitHub大学目录，中小学保留GitHub备用。三个初始入口均为按钮；点击先显示目标平台/域名及联网、可能登录提示，可取消，仅确认弹窗内的“继续前往”是外链。浏览器验证官方入口弹窗且URL不变，取消后大学入口显示正确目录；未实际跳转或登录外部平台。发布构建、4189路由回归、签名及包内私人签名密码/本机路径比对通过；初始静态HTML没有可直接打开官方平台的链接，避免水合前绕过确认。
