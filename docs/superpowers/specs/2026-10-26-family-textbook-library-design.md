# 家庭教材入口方案

状态：用户于 2026-10-26 确认采用简化方案。

## 目标

家人知道去哪里查找和下载教材，不依赖 GitHub 作为主要入口，也不增加复杂的教材下载系统。

## 确认的行为

- 教材中心提供国家中小学智慧教育平台的固定官方入口：https://basic.smartedu.cn/tchMaterial。
- 提示按学段、年级、学科和教材版本查找，下载与是否需要登录以官方页面提供的功能为准。
- 登录在官方平台完成，本应用不收集、保存或代填国家平台账号。
- GitHub ChinaTextbook 仅保留备用入口：https://github.com/TapXWorld/ChinaTextbook。
- 不再在应用内同步、展示全量 GitHub 教材书目。外部访问失败不影响内置课程、练习与本地进度。
- 本轮不增加 PDF 阅读器、私有教材服务器、后台抓取或自动下载。外部平台的文件不会自动变成 APK 内的离线教材。

## 同轮界面调整

移除“我的”页面的打赏支持入口；家庭 AI 服务作为独立卡片移到家长时间设置下方、数据备份上方，不占据页面头部。

## 验收

最终 APK 的教材页应包含上述两个固定 HTTPS 外链和清楚的登录/下载指引，无全量目录加载请求；“我的”页没有打赏入口，家庭 AI 卡片位于家长设置之后。保留相同家庭包名和签名，以支持直接覆盖安装。私人配置与密钥仍不进入源码或安装包。

用户补充确认：中小学入口跳转国家中小学智慧教育平台；大学教材独立链接到 GitHub ChinaTextbook 的大学目录。中小学仍保留 GitHub 根目录备用入口。

所有教材外链先显示目标平台、联网及可能登录的提示，确认“继续前往”后才跳转；可取消。初始入口为按钮，避免页面水合前直接跳转。
