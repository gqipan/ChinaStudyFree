# 家庭安卓 APK 首版方案

状态：用户已确认实施；2026-10-26。本文不含真实部署配置或家庭信息。

## 目标与选择

家人安装一个 APK 后即可进入学习页面。课程与练习随安装包提供；在线 AI 使用现有私有服务器，模型密钥留在服务端。

推荐沿用 Capacitor，将静态页面和已有课程打入 APK。相比仅加载线上网页的 APK，此方式支持离线练习，但课程更新需要重新安装新版。另一个选择是原生安卓重写，投入明显更大，首版不采用。首版用于家庭侧载分发，不增加应用商店发布或 iOS 工作。

## 已核实的起点

- 当前 main 工作区干净，HEAD 为 ad30762；origin 为用户 Fork，upstream 为原项目。
- apps/mobile 已配置 Capacitor 6，静态页面目录为 apps/web/out。
- 安卓工程被忽略，当前未提供可复用的受版本控制工程；现有 CI 直接执行 sync，不能假定干净检出后能构建。
- 当前客户端 AI 请求未携带家庭认证；当前服务端允许宽泛 CORS。存在安全修复远端分支，实施时先核对改动，再决定复用范围。
- 当前常见安装路径未发现 Android SDK、Android Studio 或 node_modules；发现的 JDK 为 Java 8。工具链是否在其他路径仍需检查。
- README 提及演示签名。家庭版发布不能依赖公开演示密钥。

## 必须满足的离线底线

用户明确要求：AI 不可用也必须保证应用可用。断网、认证失败、AI 超时或服务故障均不得阻断启动、进入课程、本地答题和进度保存。

## 首版行为

1. 保留现有名称、课程导航和选年级流程，使用独立应用 ID `com.chinastudyfree.family`，与上游安装包并存。首次发布前固定此 ID，后续更新保持不变。
2. 安装后即可使用打包课程和题目，无需联网登录。教材 PDF 外链、未实际打包的音频或图片不承诺离线可用；缺失时显示明确提示或使用现有降级。
3. 在设置中提供“家庭 AI 服务”：由家长输入 HTTPS 服务地址及家庭账号密码，并测试连接。地址保存在设备，凭据首版仅保留在当前运行会话内，完全重启后需重新输入。页面说明这一点；后续若需要免登录，再增加基于 Android Keystore 的凭据保存。
4. 仅向配置的 HTTPS 源发送认证，拒绝带 userinfo、查询参数、片段的服务地址。服务地址变更或退出时清除会话凭据；AI 响应不把密码或上游错误详情展示给用户。
5. AI 出题和在线语音共用请求入口，处理认证失败、无网络、超时和服务未配置。请求失败不阻断本地课程，更新连接配置后可重新探活。
6. 学习记录首版沿用每台设备的本地存储与现有备份能力；不增加云同步、多人档案或儿童个人资料收集。

## 服务端与隐私边界

移动端请求使用手动输入的家庭认证，通过 HTTPS 访问现有认证网关。实施时核对真实网关的 OPTIONS、Authorization 与 CORS 处理；预检不应绕过实际 API 认证。源允许列表是浏览器访问控制，不能替代服务端认证。

先在本地完成服务端/代理模板及验证，不把生产配置写入公开代码。线上变更需要明确记录实际适配项和部署验收，不能仅凭本地模拟宣称 AI 已可用。

仓库只保存通用源码、构建脚本及脱敏模板。真实服务器地址不编入通用安装包；家庭密码、模型密钥、签名密钥、学习备份和私人验收记录均不提交 Git。签名文件使用仓库外路径，产物保存在忽略目录。禁止在日志中输出认证头、配置值或用户输入的学习内容。

## 构建与交付

提供从干净检出开始的流程：安装锁定依赖 → 生成课程数据 → 静态构建 → 创建/同步安卓工程 → 应用家庭版原生配置 → 编译 → 签名与校验。同步命令从正确的 mobile workspace 执行。生成工程的配置必须由受版本控制的模板或脚本可重复恢复。

先输出明确标记的调试 APK 验证，再输出使用私人密钥签名的家庭分发 APK，并附 SHA-256 与安装说明。两类签名不能直接互相覆盖；调试与家庭发布采用不同应用 ID，防止切换包类型时误删学习数据。家庭发布保持固定签名和递增 versionCode，支持覆盖更新。

本地优先构建。若缺工具链，先核实安装位置、磁盘与下载需求，补齐后再构建；不能以已有上游 Release 代替定制版。真实家庭凭据和签名不进入公共 CI 构建产物。

## 验收

- 类型检查、现有核心测试和静态构建通过。
- 新增有实际意义的连接验证测试：HTTPS 地址限制、凭据只发往指定源、401/超时降级、切换地址清除会话。
- 干净生成的安卓工程能够编译；验证签名、应用 ID、版本号和包内敏感信息。
- 安卓设备或模拟器验证首次启动、选年级、完成练习、断网练习、返回键、重启后的学习记录以及发布包覆盖更新。
- 通过真实服务验证认证失败、连接成功、AI 出题和语音。没有可用设备或生产连接条件时分别标记待验收，不宣称已通过。
